# Product Paths

## Open source

Keep the Capability Contract, runtime, WebMCP adapter, examples and conformance tests free.

Goal: adoption, credibility, shared vocabulary and ecosystem contributions.

## WIZNEO — Agentic Web Lab

Use this repo to build before teaching:

- browser actuation vs WebMCP benchmarks;
- real integration walkthroughs;
- security failures/fixes;
- agent-ready website builds;
- commerce experiments;
- standards changes backed by code.

## GNOSIX — Agent Readiness

Commercial question:

> Can agents read, discover, operate and transact with this business — and can they do it safely?

Potential deliverables:

- capability inventory;
- evidence-backed readiness score;
- risk map;
- remediation architecture;
- safe implementation;
- governance/observability.

## Hosted scanner / CI

Possible SaaS:

- scan every deploy;
- detect missing/changed tools;
- compare schemas/effects;
- enforce policy;
- run eval suites;
- preserve evidence/history;
- alert on new consequential surfaces.

## Enterprise governance

- ownership;
- approvals;
- version lifecycle;
- environment promotion;
- kill switches;
- audit/SIEM export;
- org allow/deny policy.

## Commerce/payments

Later high-value layer:

- checkout intent;
- merchant capabilities;
- user mandates/budgets;
- transaction receipts;
- UCP/AP2/provider adapters.

Do not process raw payment credentials in the generic runtime.

## What not to build first

Do not begin with another repo-to-WebMCP generator. That wedge already exists. The stronger position is **contract + policy + evidence + multi-protocol readiness**.
